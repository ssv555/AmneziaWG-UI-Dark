# История версий

Каждая версия выкладывается на странице [Releases](https://github.com/ssv555/AmneziaWG-UI-Dark/releases) готовым
`awg-ui.exe`. Новые сверху.

| Версия | Дата | Изменения |

любой диалог можно запомнить, «Настройки - Снова показывать скрытые диалоги» возвращает их<br>Добавлено: проверка апстрима: сообщает, что закреплённые версии движка перестали быть новейшими<br>Изменено: у каждого окна и диалога есть заголовок, за который их можно перетащить, кнопка закрытия и закрытие по Esc<br>Изменено: даты везде в виде ГГГГ.ММ.ДД; программа, занявшая имя канала ядра, больше не может вызвать откат |
