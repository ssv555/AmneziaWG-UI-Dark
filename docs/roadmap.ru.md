# Планы

Полные списки по версиям - в [журнале изменений](../CHANGELOG.ru.md). Здесь только суть каждой версии.

## Сделано

1. **0.1.0** (2026.10.03): окно туннелей поверх установленного AmneziaWG: группы, подключение и отключение, живое
   состояние и график, тёмная тема, демо-режим.
2. **0.2.0** (2026.10.03): таблица туннелей с поиском и статистикой, график скорости с пингом, журнал событий,
   значок в трее и уведомления, автозапуск.
3. **0.3.0** (2026.10.03): готовый `awg-ui.exe` в GitHub Releases; источники конфигураций и редактор; русский язык
   встроен, свои языки - файлами `.lng`; масштаб интерфейса.
4. **0.4.0** (2026.10.05): служба-ядро `AwgUiCore` (VPN работает при закрытом окне, в окне нет запросов UAC);
   встроенный движок (режим 2) без установленного AmneziaWG; несколько туннелей одновременно; автоматическое
   переподключение; окно обновлений и откатов с подписанными манифестами и копиями; проверка исходников движка.
5. **0.5.0** (2026.10.06): ядро занимается только VPN, остальное работает в отдельном процессе-помощнике
   (`awg-ui.exe --agent`), который ядро перезапускает; туннели в меню трея; фильтр, поиск и копирование в журнале
   событий; проверка конфигурации в редакторе; копирование значений карточки и диагностики; ежедневное напоминание
   о доступном обновлении; eframe 0.36 и wgpu 30; исправления и обновление зависимостей.
6. **0.5.1** (2026.10.06): защита от случайного отключения туннеля (сначала вопрос, двойной щелчок и Enter
   только подключают); ядро перезапускает туннель, у которого перестало обновляться рукопожатие; окно «Настройки» с
   «ОК» / «Отмена» / «Применить» вместо выпадающего меню; доступ к меню с клавиатуры (F10, Alt, Alt+буква, стрелки,
   Ctrl+N, Ctrl+I, F1, F5); поддержка экранного диктора (дерево доступности, подписи у нарисованных строк, графика и
   точек состояния).
