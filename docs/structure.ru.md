# Структура проекта

См. также: [архитектура](architecture.ru.md), [модули](modules.ru.md).

## Корень репозитория

```
.
├── src/             исходный код программы (ниже)
├── tests/fixtures/  образцы подписанного манифеста для тестов обновлений (src/update)
├── engine/          скрипты сборки и проверки встроенного движка (tunnel.dll, wintun.dll)
├── assets/icon/     иконки PNG, по одной на размер; build.rs вшивает их в exe
├── img/             скриншоты для README
├── docs/            эта документация
├── build.rs         вшивает иконку и сведения о версии, закрепляет хеши файлов движка
├── Cargo.toml       пакет и зависимости (Cargo.lock фиксирует их версии)
├── .cargo/          флаги сборки: статическая среда выполнения C, VC++ Redistributable не нужен
├── .github/         процессы CI, выпуска и проверки upstream, Dependabot
├── README.md        документация для пользователя (README.ru.md — на русском)
├── CHANGELOG.md     история версий (CHANGELOG.ru.md — на русском)
└── CONTRIBUTING.md, LICENSE
```

## `src/`

Файлы верхнего уровня, по слоям. Слои описаны в [модулях](modules.ru.md).

| Путь | Назначение |
|---|---|
| `main.rs` | Точка входа: по командной строке выбирает роль (окно, ядро, агент, служба туннеля, помощники, команды установки и состояния) |
| `app.rs`, `app/` | Окно (egui): состояние, таблицы, диалоги, меню; см. ниже |
| `monitor.rs` | Опрос раз в секунду: список и состояние туннелей, история графика, события переходов, состояние трея. В ядре опрашивает туннели (`poll`, `core_state`); в окне отражает состояние ядра (`spawn`) и агента (`spawn_agent`); `Stamp` помнит, с какого момента окно видит ядро и агента в нынешнем состоянии (для отчёта диагностики) |
| `daemon/` | Служба ядра, агент и их протоколы; см. ниже |
| `update/` | Обновления и откаты трёх компонентов; см. ниже |
| `backend.rs` | `TunnelHost`: подключение, отключение и состояние туннелей режима 1 (`Real`), режима 2 (`EngineHost`) и демо (`Demo`) |
| `engine.rs` | Режим 2: службы туннелей, установка и проверка файлов движка |
| `store.rs` | Хранилище конфигов режима 2 (файлы, зашифрованные DPAPI) |
| `archive.rs` | Импорт из zip и резервные архивы с паролем |
| `native.rs` | Управление родным окном AmneziaWG через UI Automation |
| `uapi.rs` | Состояние туннеля по каналу UAPI WireGuard |
| `conf.rs`, `conf/check.rs` | Сведения о туннеле, разобранные из файла `.conf`; проверка конфига по правилам разбора движка (ключи, адреса, Endpoint, параметры AmneziaWG), ошибки с номерами строк под редактором |
| `scm.rs` | Управление службами Windows за одним интерфейсом, с подделкой для тестов |
| `win.rs` | Windows-специфика: проверка прав администратора, заголовок и рамка окна под тему, служба менеджера, автозапуск, один экземпляр |
| `elevated.rs` | Запуск своего exe с правами администратора (UAC) и получение его итога |
| `events.rs` | Журнал событий: модель, кольцо в памяти, файл `events.log` с ротацией |
| `stats.rs` | Модель накопительной статистики по туннелям и формат `Stats.ini` |
| `ping.rs` | ICMP-пинг через VPN и его состояние; проверка узла пинга (`valid_host`) |
| `groups.rs` | Книга туннелей: вложенные группы, назначения, выбор |
| `settings.rs` | Настройки окна (`Settings.ini`), тип режима работы и тема окна (`Theme`: `graphite`, `slate`, `daylight`, `system`; неизвестное значение → `graphite`) и масштаб графика (`GraphRange`, `[layout] graph_range`: `2m`, `10m`, `1h`, `day`, `month`, `year`; неизвестное значение → `2m`; ключ 0.5.3 `graph_period` в секундах читается при переходе) |
| `health.rs` | Состояние туннеля -> уровень (цвет точки, значок в трее, события) и текст |
| `i18n.rs` | Локализация: английский по умолчанию, русский встроен, остальные языки — из `lang\*.lng` |
| `ini.rs` | Минимальное чтение и запись INI |
| `fmt.rs` | Форматирование чисел и времени |
| `fsutil.rs` | Атомарная запись, текст ошибки с путём, проверка имён, ожидание с пределом |
| `crash.rs` | Хук паники, изолированное выполнение, восстановление блокировок, нефатальные циклы потоков |
| `tray.rs`, `taskbar.rs`, `icon.rs`, `shortcut.rs` | Значок в трее и уведомления, кнопка в панели задач и значок поверх неё, иконка программы, ярлык на рабочем столе |

### `src/app/` (окно)

| Файл | Назначение |
|---|---|
| `window.rs` | Состояние окна: размер и положение, закрытие, запись настроек, масштаб, `--snapshot` |
| `list.rs`, `list/rows.rs` | Таблица туннелей: колонки, клавиатура, строки групп и туннелей, меню, перетаскивание; главное действие с туннелем (`Primary`: кнопка, меню, трей; двойной щелчок и `Enter` только подключают) и правило подтверждения отключения (`asks_first`) |
| `details.rs`, `graph.rs`, `status.rs` | Сведения о выбранном туннеле (правый щелчок по значению — «Копировать»; приватный и общий ключи не показываются и не копируются), график скорости с полосой пинга (шкала скоростей справа; кнопка паузы: снимок графика и полосы пинга на время работы окна, `GraphPause`, снимается при показе другого туннеля или масштаба с другим источником; выпадающий список масштаба: 2 мин, 10 мин и 1 ч — по замерам окна, день, месяц и год — по истории агента), строка состояния |
| `history_feed.rs`, `history_graph.rs` | История скорости для масштабов «День», «Месяц» и «Год»: `HistoryFeed` спрашивает агента (`AgentApi::history`) в фоновом потоке — сразу при смене туннеля или масштаба, потом раз в минуту, пока график показан; кадр только читает последний ответ. `history_graph` рисует средние линиями, пики тонкими линиями, разрыв там, где интервала нет, ось времени — местные часы (день), местные даты (месяц) или месяцы UTC (год), подсказку со временем интервала, средними, пиками и временем подключения; вместо кривых — «Загрузка истории…», «Истории пока нет» или «История недоступна» (причина — в подсказке) |
| `event_log.rs` | Панель журнала событий: фильтр по важности и туннелю, поиск, копирование, «Сохранить как…»; фильтр — чистая функция (`visible`) |
| `menu.rs`, `theme.rs` | Строка меню и её клавиатура (`MenuNav`: F10, одиночный Alt, мнемоники Alt+буква, стрелки и подменю, горячие клавиши команд; фильтр окна для `SC_KEYMENU`), единый помощник контекстных меню (правый щелчок, Shift+F10, клавиша меню); палитры тем (`Palette` по ролям: Графит, Сланец, День; активная — `palette()`, `resolve` превращает «как в Windows» в День или Графит, `Palette::visuals` строит вид egui) и шрифты |
| `a11y.rs` | Подписи для экранного диктора у нарисованных элементов (строки туннелей и групп, график скорости, полоса пинга, точки состояния): один помощник `describe` |
| `diagnostics.rs` | Справка → Скопировать диагностику: текстовый отчёт (версии, режим, Windows, состояние ядра и агента, состояние туннелей, последние 50 событий, версии компонентов), который строит чистая функция; готовый текст проходит один проход, вырезающий ключи, адреса, голые имена хостов и хост любого URL (`схема://хост…` сохраняет схему и путь, запрос и фрагмент становятся `?<query>` / `#<fragment>`; токен `метка.метка` с буквенной последней меткой, кроме имён файлов с известными расширениями, собственных адресов программы и имён туннелей), имена пользователя и компьютера и путь профиля |
| `dialog.rs`, `modals.rs`, `group_dialog.rs`, `about.rs`, `editor.rs` | Общий конструктор окон-диалогов и построенные на нём диалоги (в «О программе» есть кнопка **Скопировать диагностику**) |
| `settings_dialog.rs` | Окно «Настройки»: черновик всех параметров по разделам («Общие» со списком тем, «Уведомления и трей», «Сеть», «Режим работы»), ОК / Отмена / Применить (`dialog::dialog_ok_cancel_apply`), «Сбросить» с подтверждением; применяется через `push_options`, `Action::Autostart` и `Action::ChooseMode` |
| `core_ui.rs` | Полоса установки и обновления ядра, установка через один запрос UAC, режим от ядра, вид окна по режиму и теме (`apply_look`) |
| `engine_mode.rs` | Режим 2 в окне: смена режима, импорт, перенос из AmneziaWG, резервная копия, новый туннель, переименование |
| `updates.rs`, `reminder.rs`, `markdown.rs` | Окно «Обновления и откаты», сроки напоминаний об обновлении, показ описания релиза |
| `native_reopen.rs` | Открывает снова окно AmneziaWG, закрытое обновлением или возвратом AmneziaWG, по отметке агента `native_ui` |
| `sources.rs`, `watcher.rs` | Файлы-источники `.conf`, открытые на правку, и кэш сведений о конфигах |
| `exit.rs`, `errors.rs` | Выход с вопросом про VPN, ошибки действий в журнал событий |
| `tray_menu.rs` | Меню трея с туннелями (группы — подменю) и его щелчок: тот же запрос переключения и то же главное действие (`list::Primary`), что у окна; отключение сначала подтверждается в окне (`list::asks_first`); без связи с ядром — пояснение первой строкой, туннели без отметок и серые; щелчок по уведомлению о туннеле выбирает туннель |
| `demo_core.rs` | Подделка ядра для `--demo` |

### `src/daemon/` (ядро и агент)

| Файл | Назначение |
|---|---|
| `mod.rs` | Константы ядра, `Config` (`core.ini`), трейт `CoreApi`, тест ограды ядра |
| `service.rs` | Вход службы Windows: диспетчер, состояние, остановка и выключение |
| `server.rs` | Работа ядра: потоки, сервер канала, обработка запросов, переключение, смена режима, `HoldNative` и `Release` |
| `retry.rs`, `deadwatch.rs`, `restore.rs`, `netwatch.rs` | Расписание переподключения, перезапуск мёртвых туннелей, правила желаемого набора, сигнал смены сети |
| `agent_watch.rs` | Сторож агента: объект задания, паузы перезапуска, проверки `Hello` |
| `pipe.rs`, `proto.rs` | Канал ядра (права, сроки) и протокол окно-ядро |
| `budget.rs` | Места соединений (владелец, SYSTEM, запас для `Hello`), общие для каналов ядра и агента |
| `install.rs` | Установка, обновление и удаление службы ядра |
| `session.rs`, `helper.rs` | Запуск помощника в сеансе пользователя и сам помощник |
| `fake.rs` | Подделка ядра для тестов |
| `phase_trace.rs` | Хронометраж пути Switch, только в тестах; в сборке без тестов пуст (см. [разработку](development.ru.md#журналы-нестабильных-тестов)) |
| `agent/mod.rs` | Процесс агента: сервер канала, разбор запросов |
| `agent/proto.rs`, `agent/client.rs` | Протокол агента; клиент со стороны окна и выбор канала для запроса |
| `agent/core_poll.rs` | Опрос состояния ядра раз в секунду, общий для языка, статистики, истории скорости и журнала |
| `agent/language.rs` | Язык агента: `language` ядра из `core.ini`, перечитывается при изменении файла |
| `agent/journal.rs` | Запись `events.log` |
| `agent/stats.rs`, `agent/ping.rs`, `agent/settings.rs` | Статистика, пинг, `agent.ini` |
| `agent/history.rs` | История скорости туннелей (ряды за сутки, месяц и год) и `history.bin` |
| `agent/updates.rs` | Запуск менеджера обновлений и перенос его записей в журнал |
| `agent/tunnels.rs` | Запросы о конфигах: хранилище режима 2 и помощник родного окна |

### `src/update/` (обновления и откаты)

| Файл | Назначение |
|---|---|
| `mod.rs` | Операции обновлений и состояние для окна |
| `manager.rs` | Менеджер: проверки, резервная копия перед каждым обновлением и откатом, установка, история, ежедневная проверка |
| `component.rs`, `component/native.rs` | Стратегия по компонентам: оригинальный AmneziaWG (MSI), движок, программа; MSI при удержании туннелей |
| `native.rs` | Оригинальный AmneziaWG: установленная версия, проверка подписи установщика, установка и удаление |
| `ours.rs`, `ours/` | Наши релизы: загрузка, проверка, транзакция над набором файлов, копии движка и программы, `--restart-core` и возврат набора |
| `sources.rs`, `feed.rs`, `net.rs` | Источники обновлений, релизы GitHub, загрузка по HTTPS через WinHTTP |
| `sign.rs` | Подписанный манифест релиза (Ed25519, SSHSIG) и SHA-256 |
| `history.rs`, `backup.rs`, `jsonstore.rs`, `restore_target.rs` | Модель истории, папки копий, файлы JSON с атомарной записью, что возвращает кнопка «Вернуть» |
| `rows.rs`, `busy.rs`, `clock.rs`, `engine_tag.rs` | Модель строк окна, модель идущей работы, часы планировщика, версии движка, общие с `build.rs` |
| `core_link.rs`, `core_link/pipe_core.rs` | Что обновления просят у ядра (`HoldNative`, `Release`, `ReconnectEngine`) и его реализация по каналу |
