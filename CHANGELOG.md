# Changelog

Every version is published on the [Releases](https://github.com/ssv555/AmneziaWG-UI-Dark/releases) page as a ready
`awg-ui.exe`. Newest first.

| Version | Date | Changes |
|---------|------|---------|
| [0.4.0](https://github.com/ssv555/AmneziaWG-UI-Dark/releases/tag/v0.4.0) | 2026-10-05 | Added: the core service. Tunnels, statistics and the event log live in the `AwgUiCore` service, so the VPN keeps working when the window is closed, and the window needs no administrator rights and shows no UAC prompts<br>Added: built-in engine mode (working mode 2) that works without an installed AmneziaWG: encrypted tunnel storage, import from `.conf` / `.zip` or from AmneziaWG in one click, password-protected backups, new tunnel, rename. The icon, taskbar button and frames turn yellow in this mode<br>Added: several tunnels at once (Settings); a tunnel that cannot run together with a connected one (same address, or both route all traffic) replaces it, and the event log says why<br>Added: active tunnels come back after a reboot, power loss or a drop: the core keeps reconnecting a tunnel you left connected — every 10 s for 3 minutes, every minute up to 10 minutes, then every 10 minutes until it works, and at once when the network changes; the tunnel shows the attempt, after 10 minutes the reason and a Retry button, plus one notification<br>Added: updates and rollbacks window (Help - Check for updates): native AmneziaWG, the built-in engine and the app, each separately or all at once; automatic backup before every update, history with a Restore button, the previous build is put back automatically if the updated core does not start<br>Added: a daily background check with a small notice at the bottom right (Open / Later) that does not steal focus; a separate What's new window; the engine row is compared with the version in Amnezia<br>Added: confirmations on exit (disconnect and exit, or exit and keep the VPN running) and on switching the working mode, with the list of affected tunnels; every dialog can be remembered, Settings - Show hidden dialogs again brings them back<br>Added: an upstream check that tells when the pinned engine sources are no longer the newest<br>Changed: every window and dialog has a title bar you can drag, a close button and closes on Esc<br>Changed: dates are shown as YYYY.MM.DD everywhere; in the updates window both version columns show the release date, the install date is in the tooltip<br>Changed: the taskbar dot is a real overlay badge on the button; the button icon is yellow in the built-in engine mode and no longer duplicated by a desktop shortcut<br>Changed: errors of actions go to the event log and to `window-errors.log` instead of being lost; both logs are rotated by size<br>Changed: if the core stops answering, tunnels show Unknown: no connection to the core instead of a guess, the tray and status bar warn, and everything returns once the core answers<br>Fixed: unreadable `Settings.ini` / `core.ini` are no longer overwritten: the file is kept as `*.unreadable-<date>` and the problem is logged<br>Fixed: long-uptime robustness: an internal error in one request or update job no longer takes the core down, background failures are visible, event log rotates without a restart, pipe and child-process waits have time limits, a failed tray icon is re-added, statistics of deleted tunnels are dropped after 90 days<br>Fixed: Explorer hangs can no longer freeze the window or the tunnel monitor; renaming or deleting a tunnel moves or removes its group, source and selection together<br>Security: updates are checked before installing: the AmneziaWG installer by SHA-256, publisher signature and MSI identity, our engine and app by a signed manifest; at most 5 backups per component are kept<br>Security: a rollback needs administrator rights (UAC), so no other program can silently downgrade a component; the elevated helper reports back through a private channel instead of a file in `%TEMP%`; a program that grabs the core pipe name can no longer trigger a downgrade |
| [0.3.0](https://github.com/ssv555/AmneziaWG-UI-Dark/releases/tag/v0.3.0) | 2026-10-03 | Ready-to-run `awg-ui.exe` on GitHub Releases<br>Version in the window title<br>Connection-state dot on the taskbar button (Settings switch)<br>Interface scale on top of the Windows scale: View menu, `Ctrl+Plus` / `Ctrl+Minus`<br>A failed ping shows the last value and n/a instead of an error text<br>The About window hides the account name in paths<br>Sharper README screenshots; demo mode with realistic traffic and events |
